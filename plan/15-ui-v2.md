# 15 — Giao diện v2

Mục tiêu: làm lại giao diện 6 trang cho dễ nhìn, gọn và dễ thao tác hơn, theo bản thiết kế ở [design/desktop/v2/](../design/desktop/v2/) (mô tả từng trang: [design/README.md](../design/README.md)). Chỉ đổi giao diện, không đổi API ghi hay quy tắc an toàn. *(người dùng yêu cầu 2026-11-28)*

## Đã chốt khi duyệt design (2026-11-28)

- **Màu chính tách khỏi màu trạng thái**: thêm `--primary` (nút chính, mục đang chọn, tab, công tắc, link) riêng với `--accent` xanh lá (giữ nghĩa "sạch / qua / đã stage / đang chạy"). Mặc định màu chàm `#8B93FF` (chữ trên nút `#11143A`); design có bộ chọn 4 màu để so (chàm, ngọc, hổ phách, xanh lá cũ). **Còn chờ người dùng chọn màu cuối.**
- **Panel kéo đổi độ rộng, nhớ lại**: panel trái mọi trang và khung chi tiết Git / Jira / Job / Remotes có tay kéo ở mép (nhấp đúp về mặc định, ←/→ khi focus), nhớ theo từng trang.
- **Chi tiết dạng panel ↔ cửa sổ nổi**: Git (đã có), Jira, Job, Remotes dùng chung một cách chuyển, nhớ lựa chọn theo trang. Mặc định Git, Jira là panel; Job, Remotes là cửa sổ nổi (giữ hành vi hiện tại).
- **Tổng quan là bảng tổng hợp cả 5 trang**: hàng chỉ số; "Cần xử lý" gom việc từ mọi trang; thẻ gọn từng trang; thiết lập thu gọn ở cuối. Vẫn không quét repo khi mở trang.
- **Job cùng repo gộp một khối**: đầu khối là repo + nhánh + đường dẫn, các job là các dòng trong khối.
- **Biểu đồ đường "Theo repo"** ở trang AI: mục riêng trong [07-ai-usage.md](07-ai-usage.md).

## Cách làm chung

- Thứ tự: **15a nền chung → 15b khung chi tiết → từng trang 15c–15h**. Mỗi mục con một commit, chạy `npm run typecheck && npm test` trước khi commit; trang nào xong thì mở `npm run desktop:dev` so với file design ở 1280×800 và 1100×700.
- Design là HTML thuần, chỉ dùng làm **mẫu bố cục, khoảng cách, chữ**; code thật vẫn dùng component sẵn có (`ui.tsx`: `Chip`, `Segmented`, `Select`, `Kpi`, `KpiStrip`, `ShareBar`, `Icon`, `NavLabel`; `Modal`; `ContextMenu`) và Tailwind theo token ở `src/styles.css` `@theme`.
- Không đổi `server/`, trừ API gom "Cần xử lý" ở 15c (chỉ đọc).
- Lớp CSS trong design ↔ code: `.panel` ↔ `.panel`, `.kpi` ↔ `Kpi`, `.seg` ↔ `Segmented`, `.chip.ok|up|down|bad` ↔ `Chip tone="ok|ahead|behind|danger"`, `.ri` ↔ `.nav-item`, `.side h4` ↔ `NavLabel`, `.br` (chip nhánh) ↔ `BranchChip`, `.jk` ↔ `JiraKey`.

## Rủi ro

- **Đổi nhiều trang một lúc dễ vỡ chức năng cũ**: làm từng mục con, mỗi mục một commit, giữ nguyên API.
- **Nhầm nghĩa màu khi đổi `accent` → `primary`**: rà từng chỗ theo danh sách ở 15a, chụp màn hình trước / sau.
- **Tổng quan gom dữ liệu nhiều nguồn**: chỉ đọc cache, không kích hoạt quét git hay gọi GitLab / Jira khi mở trang; mỗi thẻ tự lỗi riêng, không làm hỏng cả trang.
- **Khóa localStorage cũ**: giữ `git.detailMode`, `git.detailW`, đọc `devdeck.sidebar.w` làm mặc định khi chuyển sang khóa theo trang.
